## Deviations from Design

- **authPromise vs whenReady()**: Used `authPromise` (module-level deferred promise) instead of `whenReady()` method on AuthContext. The orchestrator's specific instructions were more detailed, and the module-level promise is cleaner for TanStack Router's `beforeLoad` pattern since it doesn't require context access.
- **Login.tsx search params**: Used `URLSearchParams(window.location.search)` instead of `useSearch` from TanStack Router to avoid circular import between route and page files.
